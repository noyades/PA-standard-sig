Step 3

Review and submit

How a submission travels. This site is served as static files and has no upload endpoint, so the handoff is deliberate: download the bundle, open the prefilled issue, and attach the bundle to it. The issue arrives carrying every field you filled in, so nothing has to be re-typed. GitHub caps an attachment at 25 MB — for anything larger, attach the metadata alone and link the waveform from a file host in the issue.

Step 2

Describe the signal

Fields appear and disappear as you answer — a standards-based waveform is described by its MCS and channel bandwidth, a custom one by its modulation, filter and symbol rate. Required fields are marked.
